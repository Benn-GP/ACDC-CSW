# ACDC SmartFix — Sistema de Gestión de Taller Técnico

Aplicación de escritorio para la gestión de clientes, recepción de equipos y diagnóstico técnico de **ACDC Electronics Lab (Cusco)**, desarrollada en Python con CustomTkinter y SQLAlchemy.
